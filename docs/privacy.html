Polityka prywatności – Skroty Futbol Bot

Ostatnia aktualizacja: 1 listopada 2026

Kto korzysta z aplikacji

Skroty Futbol Bot to prywatne narzędzie używane wyłącznie przez jego właściciela, Michała Polaka. Aplikacja nie jest udostępniana innym użytkownikom.

Jakie dane są używane

Po autoryzacji przez właściciela aplikacja korzysta z YouTube Data API, aby: odczytywać publiczne informacje o filmach (tytuły, czas trwania, liczbę wyświetleń) oraz tworzyć i aktualizować playlisty na kanale właściciela.

Aplikacja nie zbiera, nie przechowuje ani nie przetwarza danych osobowych żadnych innych osób.

Przechowywanie i udostępnianie

Jedyną przechowywaną informacją jest token dostępu do konta właściciela, trzymany jako zaszyfrowana zmienna środowiskowa na serwerze, na którym działa bot. Dane nie są sprzedawane ani przekazywane osobom trzecim.

Wykorzystanie danych z interfejsów API Google jest zgodne z zasadami dotyczącymi danych użytkownika w usługach interfejsu API Google, w tym z wymaganiami ograniczonego użytkowania.

Cofnięcie dostępu

Dostęp można w każdej chwili cofnąć na stronie myaccount.google.com/permissions.
